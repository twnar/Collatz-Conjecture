The Collatz Conjecture

Choose a positive integer. If it’s even, divide by 2. If it’s odd, multiply by 3 and add 1. Repeat the cycle. The terrifying beauty of this rule? Every number in existence eventually gets trapped in the exact same loop: 4, 2, 1. A simple rule with an unproven secret!
